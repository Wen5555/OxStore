已在购物车中的商品随后下架或售罄：该行保留并标注「已下架」，由客户手动删除，不自动删除、不自动调减数量。商品仍在售但库存大于 0 且少于车中数量：该行不标注失效、保持原数量，下单时再因库存不足被拒绝。

### 固定提示（原文摘录）

### 数据库不变量

- 金额两位小数、数量/库存为规范非负整数字符串口径（挑战B新接口）
- cart_item UNIQUE(customer_id,product_id)；quantity>0；删行后旧 id 不 upsert 复活
