# 测试数据准备与清理（可运行）

## 安全

- 仅使用库名 `oxstore_b030_*` / `oxstore_test_*`
- 商品名 `B030-*`；用户 `b030_*`
- 脚本拒绝 `DROP DATABASE`；重置只删命名空间行

## 命令

```bash
cp fixtures/env.example runs/.env.local
# 编辑 B030_DB_* / B030_SELLER_PASSWORD / B030_SUT_SHA / B030_BASE_URL

python3 scripts/prepare_fixtures.py --dry-check
python3 scripts/prepare_fixtures.py          # 注册客户、对齐商品库存
python3 scripts/reset_namespace.py --case-id <CASE>
```

账号：`b030_buyer_a` / `b030_buyer_b`；商家 `admin`（密码来自环境变量）。

## 每用例恢复

用例 `pre` / `cleanup` 均调用 `reset_namespace.py`，将车/收藏/确认/B030 订单清掉并恢复商品库存状态。
