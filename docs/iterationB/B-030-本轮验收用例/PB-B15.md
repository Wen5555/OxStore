### 验收标准原文

收藏写入与购物车行移除必须在同一事务内，要么都成功，要么都回滚，不允许对客户呈现中间结果。本操作无论成功或失败，均不生成订单、不改变商品状态、不改变库存。转入后的收藏仍按商品身份绑定，展示实时名称、价格、主图；后续失效、恢复与重新发布的规则与 `US-B09` / `PB-B09` 相同。

### 数据库不变量

- 不产生半成功中间态（订单/库存/购物车/收藏不一致）
- 金额两位小数、数量/库存为规范非负整数字符串口径（挑战B新接口）
- favorite UNIQUE(customer_id,product_id)；重复收藏不刷新 created_at
- cart_item UNIQUE(customer_id,product_id)；quantity>0；删行后旧 id 不 upsert 复活
- 成功幂等 receipt 与业务同事务；失败不留成功 receipt

### 固定提示（原文摘录）

- 「已收藏 N 件商品」
- 「已取消收藏」
- 「原转收藏已成功后，客户再取消收藏，然后重试原请求」

### 验收标准原文

提交期间商品变为已下架或不存在：拒绝该行，整次失败并回滚。一次转收藏无额外行数上限。不新增收藏批量管理功能。

### 数据库不变量

- 不产生半成功中间态（订单/库存/购物车/收藏不一致）
- 金额两位小数、数量/库存为规范非负整数字符串口径（挑战B新接口）
- favorite UNIQUE(customer_id,product_id)；重复收藏不刷新 created_at
- cart_item UNIQUE(customer_id,product_id)；quantity>0；删行后旧 id 不 upsert 复活
- 成功幂等 receipt 与业务同事务；失败不留成功 receipt
