## 加购 / SEQ-08 / SEQ-09

```bash
K=$(uuidgen)
curl -sS -X POST "$BASE/api/me/cart/items" -H "Authorization: Bearer $TA" -H "Idempotency-Key: $K" \
  -H 'Content-Type: application/json' -d "{\"productId\":\"$PID_ON10\"}"
# 提取 cartItemId 为 CID
curl -sS -X PATCH "$BASE/api/me/cart/items/$CID" -H "Authorization: Bearer $TA" \
  -H 'Content-Type: application/json' -d '{"quantity":"5"}'
# SEQ-08 双会话最后写入：
python3 scripts/barrier_runner.py --seq SEQ-08 --mode simultaneous \
  --a-cmd "curl -sS -X PATCH '$BASE/api/me/cart/items/$CID' -H 'Authorization: Bearer $TA' -H 'Content-Type: application/json' -d '{\"quantity\":\"2\"}'" \
  --b-cmd "curl -sS -X PATCH '$BASE/api/me/cart/items/$CID' -H 'Authorization: Bearer $TA' -H 'Content-Type: application/json' -d '{\"quantity\":\"9\"}'"
# SEQ-09：先删再旧 id 改量
curl -sS -X DELETE "$BASE/api/me/cart/items/$CID" -H "Authorization: Bearer $TA"
curl -sS -X PATCH "$BASE/api/me/cart/items/$CID" -H "Authorization: Bearer $TA" \
  -H 'Content-Type: application/json' -d '{"quantity":"2"}'
# 期望：该商品已不在购物车，请刷新页面后查看。
```
