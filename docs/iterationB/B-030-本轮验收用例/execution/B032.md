## 用例与命令

### PB-B13-AC1-POS（同事务成功）

```bash
python3 scripts/reset_namespace.py --case-id PB-B13-AC1-POS
python3 scripts/run_helper.py place_order --product P-ON-10 --qty 2
# 断言：message=下单成功；DB stock 10→8；所选车行按余数清理；禁止中间态文案
```

### PB-B13-AC1-NEG（失败全回滚）

```bash
python3 scripts/reset_namespace.py --case-id PB-B13-AC1-NEG
python3 scripts/run_helper.py cart_qty --product P-ON-1 --qty 5
# 记下 CART_ITEM_ID 后：

# 期望：非 2xx 或业务失败；无新订单；P-ON-1 stock 仍为 1；车行仍 5
```

### SEQ-02 同键重放

```bash
python3 scripts/reset_namespace.py --case-id SEQ-02
OUT=$(python3 scripts/run_helper.py place_order --product P-ON-10 --qty 1)
# 从 OUT 取 confirmationToken 与 idempotencyKey，同键再 POST：
curl -sS -X POST "$BASE/api/me/orders" \
  -H "Authorization: Bearer $TA" -H "Idempotency-Key: $IDEM" \
  -H 'Content-Type: application/json' \
  -d "{\"confirmationToken\":\"$CONFIRM\"}"
# 期望：订单已提交，请勿重复下单
```

### SEQ-01 库存1双买（高风险）

```bash
python3 scripts/reset_namespace.py --case-id SEQ-01
python3 scripts/run_helper.py dual_confirm --product P-ON-1 --qty 1 > runs/seq01-dual.json
python3 - <<'PY'
import json,subprocess
d=json.load(open('runs/seq01-dual.json'))['result']
base=__import__('os').environ['BASE']
def cmd(side):
    s=d[side]
    return (f"curl -sS -X POST '{base}/api/me/orders' "
            f"-H 'Authorization: Bearer {s['token']}' "
            f"-H 'Idempotency-Key: {s['idem']}' "
            f"-H 'Content-Type: application/json' "
            f"-d '{{\"confirmationToken\":\"{s['confirmationToken']}\"}}'")
subprocess.check_call([
  'python3','scripts/barrier_runner.py','--seq','SEQ-01','--mode','simultaneous',
  '--a-cmd',cmd('A'),'--b-cmd',cmd('B')])
PY
# DB：stock=0；PLACED 恰 1；失败者整单拒绝
```
