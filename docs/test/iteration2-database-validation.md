## 复验

先准备Java17、Maven、Python及运行中的Docker，并使用本机已有 `mysql:8.0.46` 镜像。脚本不会自动拉取其他标签。

```powershell
mvn -B -ntp -f backend/pom.xml clean verify
python -X utf8 scripts/verify_iteration2_database.py --java java
```

本机Maven使用既有Aliyun公共镜像配置（`aliyun-public`），未更改项目依赖版本。若系统默认Java不是17，在调用前设置该终端的 `JAVA_HOME`/PATH，或给验证脚本传入Java17的完整可执行文件路径。脚本只用Python标准库；默认输出覆盖本日期证据路径，复验留档时用 `--output` 指定新目录。

旧版夹具 [iteration1-schema.sql](fixtures/iteration1-schema.sql) 的内容来自基线版本的五表schema；迁移数据在脚本内人工构造，不包含业务导出。临时密码、JWT、完整备份和上传文件不进入公开JSON。
