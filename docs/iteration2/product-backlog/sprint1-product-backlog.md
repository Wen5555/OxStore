## 1. 用户故事与验收标准（可进计划会）

### US-01 / PB-01 多商品上架与按商品队列

**故事：** 作为卖家，我想同时维护多件在售商品，且每件商品有独立意向队列与冻结，以便并行售卖多件货。

**验收标准：**
1. 系统允许多件商品同时处于「在售」；无同时在售数量上限。
2. 每件在售商品各自维护一条意向队列；对 A 商品冻结不影响 B 商品浏览与提交意向。
3. 发布商品必填：名称、价格、二级类目（必须选到二级）、库存数量；选填：描述、图片（0～9 张）。
4. 顾客提交购买意向必须已登录；界面无口令码入口；系统不再提供口令码提交流程。
5. 每笔交易固定数量为 1；不可一次购买多件。
6. 卖家发起交易时，才将「当时该商品队首」冻结进入交易；新队首不会自动冻结。

**不在本 Sprint：** 同一顾客多队/同商品重复排的限制规则；卖家并行处理多个队首交易。

---

### US-02 / PB-02 库存与自动下架

**故事：** 作为卖家，我想为每件商品设置库存，卖出后自动扣减，卖完自动下架，以便不用手工盯库存。

**验收标准：**
1. 库存为 ≥0 的整数；创建可为 0；创建时若为 0，立即处于「已下架」且买家端不可见、不可开详情。
2. 仅当卖家标记「交易成功」时，对应商品库存减 1；提交意向、排队、冻结均不改变库存。
3. 扣减后库存仍 >0：商品状态立即回到「在售」；该商品队列自动前移，下一位成为新队首并继续排队，但不自动冻结；需卖家再次主动发起交易才冻结新队首。
4. 扣减后库存 =0：商品变为「已下架」，立即从浏览列表与搜索结果消失；买家端不可打开详情、不可提交意向。
5. 卖家将库存从 0 改为正数后，不会自动上架，必须在后台手动重新上架后才可再次在售。

**不在本 Sprint：** 库存到 0 时队内未成交意向的清空/失败等处理规则。

### US-03 / PB-03 浏览、搜索与二级类目

**故事：** 作为买家，我可以通过浏览、二级类别筛选和关键词搜索找到在售商品；作为卖家，我发布商品时必须选择二级类目。

**验收标准：**
1. 存在可用的二级类目树（一级→二级）；发布商品时必须选择到二级类目，否则无法发布。
2. 买家端支持按二级类别筛选浏览；缺筛选或未实现二级类目均视为本条未完成。
3. 浏览列表与搜索结果仅包含「在售」商品；未登录可浏览与搜索。
4. 搜索匹配商品名称与描述（不匹配类别）；结果仅在售。
5. 列表/搜索每条至少展示：名称、价格、主图、所属类别；库存仅在详情页展示。
6. 主图为第一张上传图片；若无图片，列表/搜索/详情统一显示占位图。
7. 「已冻结」商品不出现在列表/搜索；买家仅可通过商品详情直链/分享链接打开，只读，不可买、不可提交意向。
8. 「已下架」商品买家端不可打开详情、不可提交意向。

**本 Sprint 最简处理（待确认项不追问实现）：** 分页条数、搜索模糊/精确与大小写、默认排序、空关键词与无结果文案，按团队最简可运行方案实现，不单列加分项。

### US-04 / PB-04 顾客注册与登录

**故事：** 作为新顾客，我想用用户名、密码和电话注册并登录，以便提交购买意向并查看历史订单。

**验收标准：**
1. 注册必填：用户名、密码、电话；默认交易地点选填。
2. 密码长度 ≥8；用户名全局唯一；重复用户名不可注册。
3. 使用用户名 + 密码登录；电话不作登录账号；注册无需验证码。
4. 未登录可浏览/搜索；未登录无法提交购买意向（无口令码旁路）。
5. 密码不以明文存储（哈希）。

**不在本 Sprint：** 修改个人资料；失败次数锁定；电话唯一性等未裁定规则（按最简）。

---

### US-05 / PB-05 历史订单（终态）

**故事：** 作为已登录顾客，我想查看自己已有明确结果的历史订单，以便核对成交与失败记录。

**验收标准：**
1. 未登录访问历史订单时，引导登录。
2. 仅展示当前登录用户本人、且交易结果为成功或失败的记录；不展示排队中、交易中、已撤销。
3. 每条至少含：商品名称（下单时快照）、下单时间、交易结果（成功/失败）、交易时间。
4. 按时间倒序；支持分页。
5. 商品后续下架或删除，不影响已有历史记录展示；商品名仍为快照。
6. 注册前口令码时代意向：本轮不迁移、不展示。
7. 进行中意向：买家端本轮不提供跟进入口；仅卖家后台意向列表可见。

**不在本 Sprint：** 历史筛选/搜索、单条详情页、在历史中撤销意向、扩展展示字段（价格/地点等）。

## 2. Sprint 计划会建议拆分（任务粒度参考）

1. 数据模型：商品多实例、库存、二级类目、顾客账号、订单/意向终态快照
2. 废除口令码：移除入口与提交流程；提交意向改为登录校验
3. 卖家：发布/编辑（含二级类目与库存）、手动上架、按商品队列与冻结
4. 成交成功扣库存与状态机（回在售 / 自动下架）
5. 买家：浏览、二级筛选、搜索、详情直链只读规则
6. 注册登录会话
7. 历史订单列表（成功/失败）
8. 基础联调与演示脚本（覆盖 US-01～05 主路径）
