## 一、PB-01～05 首轮访谈（已裁定）

### PB-01 多商品上架

**提问要点：** 在售上限；队列/冻结是否按商品；同人多队与同商品重复排；冻结互不影响；卖家并行多笔交易；发布必填字段。

**已裁定：**
1. 同时在售无上限。
2. 每件商品各自意向队列；冻结按商品；冻结一件不影响其他。
3. 冻结一件时，其他商品可浏览并提交意向。
4. 发布必填：名称、价格、类别、库存数量；选填：描述、图片（最多 9 张）。

**当时待确认（后见文末总表）：** 同一顾客多队/同商品重复排；卖家并行多笔交易。

### PB-02 库存与零库存自动下架

**已裁定：**
1. 库存为非负整数（≥0）；创建可为 0；为 0 立即自动下架。
2. 仅卖家标记「交易成功」时库存减 1；提交意向不预占。
3. 冻结与排队均不占库存。
4. 库存到 0：状态「已下架」，立即从可买列表与搜索消失。
5. 库存从 0 改回正数后须卖家手动重新上架。

**当时待确认：** 库存到 0 时队内未成交者如何处理。

### PB-03 浏览与搜索

**已裁定：**
1. 浏览/搜索默认仅「在售」；冻结不在列表，但可打开详情（只读，不可买、不可提交意向）。
2. 搜索匹配名称、描述（不含类别）；结果仅在售。
3. 未登录可浏览和搜索；提交意向需要注册登录。
4. 搜索结果展示：名称、价格、主图、所属类别；库存仅详情页展示。
5. 按二级类别筛选为可选表述（后被矛盾追问纠正为必做，见第三节）。

**当时待确认：** 分页条数、匹配方式、大小写、排序、空搜与无结果、浏览列表字段。

### PB-04 顾客注册与登录

**已裁定：**
1. 必填：用户名、密码、电话；默认交易地点选填。
2. 密码不少于 8 位。
3. 用户名唯一；用用户名登录；电话不作登录凭证。
4. 注册不需要电话验证码。

**当时待确认：** 格式/复杂度/电话唯一/地点取值/会话退出/失败锁定/改资料等。

### PB-05 登录后查看历史订单

**已裁定（首轮）：**
1. 至少包含有明确交易结果（成功/失败）的记录。
2. 每条至少：商品名称、下单时间、交易结果（成功/失败）、交易时间。
3. 时间倒序，支持分页。

**当时待确认：** 是否含中间态、扩展字段、每页条数、筛选搜索、详情、撤销、口令码迁移、下架后历史显示等（部分在矛盾追问中已闭环，见第三节）。

## 四、矛盾追问解答（机器人最终裁定，2026-10-20）

### 问题1｜口令码 vs 登录
- **1.1 裁定：废除口令码。** 引入账号后不再需要口令码；不做并行、不做历史兼容（历史见 1.3）。
- **1.2 裁定：未登录不能提交意向。** 提交意向必须注册登录；口令码入口随废除从界面移除。
- **1.3 待课程组确认。** 注册前口令码意向是否/如何归到新账号，SRS 未写。  
  **临时边界：不迁移、不展示**——口令码时代意向本轮不进「历史下单记录」，不留实现。

### 问题2｜成交后库存仍 >0
- **2.1 裁定：回到「在售」。** 纠正「成交即下架」与库存的冲突：卖一件库存减 1；还有剩则继续在售；减到 0 才自动下架。「成交即下架」仅发生在卖出最后一件（库存刚好到 0）时。
- **2.2 裁定：** 队首成交后队列自动前移，下一位按先到先得成为新队首并继续排队；**不会自动冻结**；每笔交易由卖家主动发起，发起时才冻结当时新队首。
- **2.3 裁定：每单固定 1 件**，不允许一次买多件。库存表示「可卖几单」，不是单笔数量。

### 问题3｜类别
- **3.1 裁定：必须挂二级类目树才能发布**；单级文本/单级枚举不行；必须选到二级（一级→二级），为发布必填。
- **3.2 裁定：不能降级。** 「按二级类别筛选」与「二级类目数据」本轮都要做，砍掉任一都算缺需求。  
  → **范围影响：原延后的二级分类并入本 Sprint（见最终版待办 PB-03/US-03）。**

### 问题4｜主图 vs 图片选填
- **裁定：** 主图 = 第一张上传图片（不单设封面字段）。一张都没传时，列表/搜索/详情统一显示占位图；占位图即主图。

### 问题5｜冻结/下架详情入口
- **5.1 裁定：** 冻结商品不在列表和搜索；唯一合法入口是直链（详情 URL、分享链接等）；打开后只读，不可买、不可提交意向。
- **5.2 裁定：不允许。** 已下架（含库存 0 自动下架）商品，买家端打不开详情、不能提交意向，从买家端彻底退出。

### 问题6｜历史记录闭环
- **6.1 裁定：** 本轮历史只展示成功/失败终态；排队中、交易中、已撤销明确排除。
- **6.2 待课程组确认。** 进行中意向买家端本轮跟进入口，SRS 在废除口令码后未给替代页。  
  **临时边界：不展示**——进行中意向买家端本轮看不到；仅卖家后台「意向购买人列表」可见。
- **6.3 裁定：保留。** 历史一旦产生即留存；商品下架/删除不影响已有记录展示；商品名用下单时快照，不是「已删除」占位。

### 机器人总结
- 本轮待课程组确认共 2 条及临时边界：1.3 不迁移不展示；6.2 不展示。
- 其余 1.1、1.2、2.1–2.3、3.1、3.2、4、5.1、5.2、6.1、6.3 均为确定裁定，可写入验收标准。

## 五、闭环后的本 Sprint 规则汇总（供最终版待办引用）

1. 多商品在售；每商品独立队列与冻结；每单 1 件；废除口令码；提交意向必须登录。
2. 成交成功库存减 1；>0 回在售并队列前移（不自动冻结）；=0 自动下架且买家不可开详情。
3. 二级类目必做（发布必选二级 + 买家二级筛选）；浏览/搜索仅在售；无图用占位图；冻结仅直链只读。
4. 注册：用户名/密码/电话必填，地点选填；用户名唯一且用于登录；密码≥8。
5. 历史仅成功/失败；倒序分页；快照保留；口令码历史不迁移；进行中意向买家端不展示。
